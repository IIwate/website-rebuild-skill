# 动画与交互恢复

根据动画的实现来源选择代码移植、数据播放或观测拟合. 参数与时序应有源码、数据或运行记录支持, 验证需要覆盖驱动输入、状态更新和可见输出. 案例见 [case-studies/animation-recovery.md](case-studies/animation-recovery.md).

## 0. 依据

不通过无来源的参数调整掩盖差异. 临时实现说明尚未恢复的行为及替换条件, 不能作为最终保真结果. rogier 的原始要求是 "Do not tune visuals, motion, audio, or interaction by eye", 见案例 §0.

## 1. 恢复路径

| 来源 | 恢复方式 | 验证对象 |
|---|---|---|
| GSAP/JavaScript 参数与逻辑 | 保留参数、调用顺序和触发条件 | 时间轴事件、状态与阶段画面 |
| GLB 或其他烘焙数据 | 提取采样数据, 保留播放器语义 | 时间、插值与目标属性 |
| CSS 变量或不可直接读取的状态 | 采集参考轨迹, 必要时拟合 | 可观察变量及未参与拟合的样本 |
| 物理或程序化模拟 | 保留常量、积分与随机调用顺序 | 输入重放与状态轨迹 |

同一站点可组合多条路径. `.riv` 等资产可直接用对应播放器, 集成层仍需恢复预载、resize 和状态机调用.

## 2. 路径 A: 代码驱动

### 2.1 参数与生命周期

记录相关 duration、ease、delay、stagger、ScrollTrigger 范围及其来源. 同时确认 init/destroy 与页面切换关系. lando 的参数记录和 noomo 的过渡参数见案例 §2.1.

### 2.2 事件顺序

触发者、条件、先后关系和最短展示时长都可能影响动画. 总时长相同不足以证明同一过程, 应验证关键事件与中间状态.

### 2.3 常驻与替换组件

按源站路由生命周期决定哪些节点保留、哪些重建. rogier 通过 home -> about -> home -> project 导航断言 `.ui-header` 对象身份; lando 的 Webflow 外壳在换页后需要平台生命周期调用. 这些约定须在目标源码中确认, 不能跨框架直接套用.

### 2.4 初始状态

保留节点挂载时的样式与动画起点. opacity 0 挂载后再淡入, 与先显示再动画可能产生不同帧. 在过渡阶段采样, 不只比较最终静止状态.

### 2.5 文本拆分

文本单元、分词、换行与 U+200B/U+00A0/U+202F 等字符影响动画与布局. 使用源站算法或经验证的等价实现, 核对实际文本单元. samsy 和 oryzo 的实例见案例 §2.5 相关记录.

### 2.6 验证范围

检查参数来源、事件顺序、初始状态、常驻节点身份、文本拆分和平台生命周期中与当前改动相关的部分. 每条断言说明适用页面和触发状态.

## 3. 路径 B: 数据驱动

将源数据导出成结构化基准, 再比较播放器采样值与插值方式. `scripts/dump-timelines.mjs` 用于 GLB 动画, 其支持范围以脚本说明为准; 它不是任意二进制动画的通用解码器.

noomo 比较了相机在 t=0/5/10/19 的采样值, 使用小数点后三位精度. 该精度是项目判据, 其他场景根据数值范围与误差预算确定. 数值一致仍需检查属性绑定与可见结果, 不能仅据样本推断整条渲染链无缺陷.

从源代码恢复滚动到进度的映射. 内联 base64 纹理或 LUT 提取后校验字节, 避免提取过程改变数据. 案例见 §3.

## 4. 路径 C: 观测拟合与重放

在参考侧记录输入与可观察变量的时间序列. 内部状态不可直接读取时, 可在明确参数域中拟合, 再用独立采样点或输入序列验证. 零拟合残差可能来自欠约束, 不证明唯一实现或全部状态等价.

kimi 将编排数学与 DOM 接线分别验证, 记录与验证使用对应输入和单位. 覆盖所有相关驱动通道, 不把只在一个分支上的拟合结果推广到完整控制器.

## 5. 路径 D: 物理与程序化模拟

保留常量、时间步长、积分顺序、随机数消费和边界处理. O(n²) 接触解算、SecondOrderDynamics、LCG 与 worker 烘焙协议等都有具体行为影响. 未要求性能重构时不更换算法; 确需改动时单独验证其行为差异.

## 6. DOM 几何驱动进度

oryzo 的部分滚动进度由 DOM 几何推导, 相机轨迹另由数据文件驱动. 对这类实现, 核对相关元素矩形、scrollHeight 和视口条件, 不能仅恢复一条全局时间轴. HTML 字节相同也不自动保证布局相同, 字体和媒体状态同样影响几何.

## 7. 输入状态机

恢复闩锁阈值、触摸距离、静默窗口、目标更新和缓动. 使用带时间戳的输入序列重放, 检查状态转换及关键轨迹. 不同参数可能在有限样本上给出相同结果, 因而需要覆盖阈值两侧与不同输入通道.

涉及真实用户激活时使用浏览器输入接口, `dispatchEvent` 不产生可信用户事件. rogier 的过渡颜色记录每 120 ms 采样一次, 项目阈值为 per-sample RGB delta <= 6; 这是案例参数, 不是通用阈值.

## 8. 常见问题

临时近似实现未被替换、冷启动状态遗漏、常驻节点重建、滚动端点未覆盖及文字拆分差异都可能在最终静止截图中消失. 按这些具体风险增加状态或轨迹检查, 不用补偿 CSS 掩盖尚未恢复的机制.

## 9. 交付内容

保留必要参数来源、数据或观测基准、可运行的比较脚本以及覆盖与差异记录. 验证类型与确定性驱动分别见 `verification-gates.md`、`determinism.md`.
